
# Curriculum Vitae Webpage
This project is a modern and responsive web-based CV and portfolio for a QA Test Automation Engineer. It highlights professional experience, technical skills, and achievements in a clean, easy-to-navigate format. The site is designed for recruiters and collaborators to quickly assess expertise and contact details.

## Website
